## Generate Your First Doc

1. **Switch to a feature branch** — The extension compares your current branch against the base (usually `main`)

2. **Click "Generate Branch Docs"** in the sidebar

3. **Wait 30-60 seconds** — The AI reads your diff, understands the changes, and writes two docs:
   - **Technical Doc** — For code reviewers (what changed, why, how to test)
   - **Summary** — For stakeholders (plain English, no jargon)

4. **Click the links** to view your published docs in Confluence

### Tips
- Use the "Compare against" field to change the base branch
- Add custom instructions to focus the AI on specific aspects
- Change doc length in Settings (concise/standard/detailed)
