## Choose Your AI Provider

Repo Doc Generator supports three LLM providers:

| Provider | Best For |
|----------|----------|
| **Anthropic (Claude)** | Best quality docs, recommended |
| **OpenAI (GPT-4o)** | Good alternative |
| **AWS Bedrock** | Enterprise / no API key needed (uses IAM) |

### Get an API Key

- **Anthropic:** [console.anthropic.com](https://console.anthropic.com) → API Keys
- **OpenAI:** [platform.openai.com](https://platform.openai.com) → API Keys

Your key is stored securely in your OS keychain (never in plain text).
